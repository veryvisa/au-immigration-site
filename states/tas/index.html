塔斯马尼亚州：州担保

已按官方页面核对最后核对 2026-09-24下次复核 2026-11-23

先看结论

塔斯马尼亚州通过Migration Tasmania运作190/491州担保项目,2026-27项目年度已于2026年8月17日重新开放ROI,采用注册兴趣(ROI)加优先级评分邀请制。

境内四条通道(技术就业TSE、毕业生TSG、长期居民TER、企业经营者TBO)均须提交ROI,按Gold/Green/Orange Plus/Orange优先级属性排名后受邀申请州提名;境外仅健康/教育岗位录用通道当前开放并可获Gold Pass立即申请提名,境外邀请制通道(OSOP)2026-27项目年度不发出邀请。

2026-27 计划年度名额：塔斯马尼亚 2026-27 计划年度共获 2,050 个提名名额：190 类 1,250 个、491 类 800 个（Migration Tasmania「2026-27 Program Opening」公告，页面更新于 2026-08-05；ROI 于 2026-08-17 开放）。

2026-27项目ROI于2026年8月17日重新开放,2026年8月20日起开始每周邀请,官网每周公布邀请分数线与名额剩余情况(基于近3个月最低分平均值)。 [原文↗]

2026-27项目对优先级属性评分规则做了调整(如TSE Gold要求至少一份工作每周不少于30小时、收入门槛改用全国平均/中位工资及TSMIT),州提名服务费涨至A$387(含GST共A$425.70),提交ROI本身仍免费。 [原文↗]

塔斯马尼亚目前没有正式的劳务协议(DAMA),官网称正在探索建立,页面最后更新于2026年7月17日。 [原文↗]

塔州境外健康/教育岗位录用通道(190)

Subclass 190 Overseas Applicant (Health or Education Sector Job Offer) Pathway

适合：持健康、联合健康或教育类技能评估、已获塔州雇主正式录用的境外申请人(限ANZSCO 241/251/252/253/254大类)

本通道在2026-27项目年度继续开放,官网称获录用的境外健康/教育专业人士仍可通过本通道获得190州提名。

项目要点原文
技能评估与职业范围须持健康、联合健康或教育相关技能评估,职业须属ANZSCO 241(学校教师)、251、252、253或254大类之一。
Migration Tasmania ↗（论坛解读）
录用要求须持塔州雇主正式书面录用信,岗位与技能评估职业属同一ANZSCO三位大类,每周至少30小时;学校教师岗位须位于塔州学校。
Migration Tasmania ↗（论坛解读）
居住限制申请人及受养人过去12个月内不得在澳大利亚其他州/领地居住。
Migration Tasmania ↗（论坛解读）
雇主与待遇雇主须在塔州稳定经营至少12个月,薪资待遇不低于本地市场水平及澳籍/永居雇员标准。
Migration Tasmania ↗（论坛解读）
岗位持续性岗位须有真实、持续的用工需求,企业须有能力维持该雇佣。
Migration Tasmania ↗（论坛解读）

塔州技术就业通道(TSE)

Tasmanian Skilled Employment Pathways (TSE)

适合：在塔州从事与技能评估相符职业的技术工作者(190方向要求职业在TSE Priority Occupation清单或Home Affairs技术职业清单上,491方向清单范围更广)

2026-27项目年度ROI已于2026年8月17日重新开放,2026年8月20日起开始每周邀请;建议申请前在官网确认最新优先级属性口径。

项目要点原文
资格路径须满足以下之一:所申报职业在TSE Priority Occupation清单上,且在塔州从事与技能评估同一ANZSCO三位大类的工作满9个月(教师/医疗/联合健康职业满6个月);或不限清单,在塔州从事对口工作满15个月(适用于Home Affairs 190技术职业清单上的所有职业)。
Migration Tasmania ↗
工时上述就业期内须平均每周工作至少20小时。
Migration Tasmania ↗
居住须目前居住在塔州并计划继续居住。
Migration Tasmania ↗
工资工资须达到A$57,000/年或A$28.85/小时(不含加班费、津贴、奖金或临时工加成)。
Migration Tasmania ↗
受养人受养人不得居住在澳大利亚其他州/领地;如从其他州/领地迁来,须在申请提名前至少3个月已迁居塔州。
Migration Tasmania ↗
雇主与岗位雇主须在塔州稳定经营至少12个月,岗位须有持续真实需求(至少12个月合同且申请时至少还剩3个月),待遇不低于本地澳籍/永居雇员标准。
Migration Tasmania ↗
后续承诺获州提名后须承诺继续在塔州同行业就业至少2年。
Migration Tasmania ↗
开放先登记意向（ROI）再受邀核对 2026-09-24官方确认

塔州技术毕业生通道(TSG)

Tasmanian Skilled Graduate Pathways (TSG)

适合：在塔州完成学业的国际毕业生(所有技能评估职业均适用)

2026-27项目年度ROI已于2026年8月17日重新开放,2026年8月20日起开始每周邀请;建议申请前在官网确认最新优先级属性口径。

项目要点原文
课程要求须在塔州CRICOS注册院校完成全日制、现场授课课程,课程CRICOS时长至少92周,达到AQF5(大专)以上,或至少为与OSCA第3/4大类相关的Certificate III。
Migration Tasmania ↗
居住与学习年限须在开课起至学业结束期间在塔州居住满至少2个日历年;VET课程每周须至少15课时(学分减免不计入全日制课时)。
Migration Tasmania ↗
居住须目前居住在塔州并计划继续居住。
Migration Tasmania ↗
受养人受养人不得居住在澳大利亚其他州/领地;如从其他州/领地迁来,须在申请提名前至少3个月已迁居塔州。
Migration Tasmania ↗
博士生特例本科非在塔州完成的博士生,须在塔州居住满2年且完成至少2年博士学习后方符合资格。
Migration Tasmania ↗
开放先登记意向（ROI）再受邀核对 2026-09-24官方确认

塔州长期居民通道(TER)

Tasmanian Established Resident Pathways (TER)

适合：已在塔州居住至少3年、目前继续居住的技术工作者(所有职业均适用)

2026-27项目年度ROI已于2026年8月17日重新开放,2026年8月20日起开始每周邀请;建议申请前在官网确认最新优先级属性口径。

项目要点原文
居住年限须在塔州居住至少3年,且在澳大利亚其他州/领地居住时间不超过总居澳时间的50%,并持续居住在塔州。
Migration Tasmania ↗
经济贡献路径(四选一)雇佣收入达A$57,000/年或A$28.85/小时且近2年内工作满至少12个月;或收入达全国最低工资但低于上述门槛且近3年内工作满至少18个月;或近12个月为境外雇主/客户远程工作并居住塔州、收入达A$57,000/年或A$28.85/小时;或在塔州自主经营满至少2年、个人收入达TSMIT(目前A$79,423)且企业有净利润。
Migration Tasmania ↗
工时受雇路径下每周须至少工作20小时。
Migration Tasmania ↗
受养人受养人不得居住在澳大利亚其他州/领地;如从其他州/领地迁来,须在申请提名前至少3个月已迁居塔州。
Migration Tasmania ↗

塔州企业经营者通道(TBO)

Tasmanian Business Operator Pathway (TBO)

适合：独资或与配偶共同经营塔州企业满至少12个月的技术移民

2026-27项目年度ROI已于2026年8月17日重新开放,2026年8月20日起开始每周邀请;建议申请前在官网确认最新优先级属性口径。

项目要点原文
经营年限须独资或与配偶共同经营塔州企业满至少12个月。
Migration Tasmania ↗
盈利与收入向本人支付不低于TSMIT 85%的工资(目前约A$67,509)后企业仍须盈利,且该收入须来自真实经营活动,不能主要依赖个人存款、家庭借款等外部资金支撑。
Migration Tasmania ↗
公平雇佣培训须完成Fair Work Ombudsman在线学习中心的相关关键课程,证明了解公平雇佣规范。
Migration Tasmania ↗
特定行业要求经营按摩理疗类业务的申请人须持相关技能评估及可核实的医保提供商编号。
Migration Tasmania ↗
适用范围分包商与独立承包商不适用本通道(可考虑塔州技术就业或长期居民通道)。
Migration Tasmania ↗
关闭仅受邀核对 2026-09-24官方确认

塔州境外邀请制通道(491 OSOP)

Subclass 491 Overseas Skilled Occupation Profiles – Invitation Only Pathway

适合：获Migration Tasmania主动邀请、在境外具备可雇佣技能与经验的技术移民(2026-27项目年度暂不发出邀请)

官网明确说明该通道当前未开放:因联邦政府优先处理境内申请人签证,Migration Tasmania在2026-27项目年度不会通过该通道发出邀请;获录用的境外健康/教育专业人士仍可走190境外通道。

项目要点原文
邀请前提须先获得Migration Tasmania主动邀请方可提交ROI,个人无法主动申请。
Migration Tasmania ↗
居住限制申请人及受养人过去12个月内不得在澳大利亚其他州/领地居住。
Migration Tasmania ↗
市场调研证据须提供对塔州就业市场的调研证据,如与雇主/猎头/行业协会的联系记录及回复。
Migration Tasmania ↗
岗位说明须就近6个月内至少2个相关岗位空缺分别说明自身资历如何匹配该岗位。
Migration Tasmania ↗
资金证明须证明有足够资金支持本人及受养人在塔州求职期间至少6个月的生活。
Migration Tasmania ↗
