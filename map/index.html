常见研究路径

学生签证 → 毕业生工作签证（485） → 积分技术移民或雇主担保

毕业生签证有年龄与学历要求；它不等于永居资格，后面的每一步都要重新满足条件。

核 485 条件 →
偏远地区临时（491 / 494） → 191 永居

191 要求在偏远地区生活工作并达到一定收入年限，以官方原文为准。

核 191 条件 →
482 雇主担保 → 186 雇主提名永居

是否能走「临时转永居」（TRT）取决于在担保雇主处的工作时间与职位。

核 186 条件 →
伴侣签证：境内 820/801，境外 309/100

两段式：先获临时伴侣签证，满足时间与关系要求后审永久阶段。
